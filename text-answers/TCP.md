**6. Время отправки первого сегмента с данными (POST) и время получения ACK на него. Рассчитайте RTT (Round-Trip Time) для этого сегмента. Рассчитайте RTT для второго сегмента с данными и EstimatedRTT после получения ACK на него ($\alpha = 0.125$).**

| Сегмент | Время отправки | Время ACK | Sample RTT |
| :--- | :--- | :--- | :--- |
| **Data 1 (POST, Frame 4)** | $0.022414\text{ с}$ | $0.044828\text{ с}$ (Frame 5) | $RTT_1 = 0.044828 - 0.022414 = \mathbf{0.022414\text{ с}}$ |
| **Data 2 (Frame 6)** | $0.022414\text{ с}$ | $0.067242\text{ с}$ (Frame 7) | $RTT_2 = 0.067242 - 0.022414 = \mathbf{0.044828\text{ с}}$ |

* **EstimatedRTT ($\alpha = 0.125$):**
  * Инициализация: $\text{EstimatedRTT}_0 = RTT_1 = 0.022414\text{ с}$.
  * $\text{EstimatedRTT}_1 = (1 - \alpha) \cdot \text{EstimatedRTT}_0 + \alpha \cdot RTT_2$
  * $\text{EstimatedRTT}_1 = (1 - 0.125) \cdot 0.022414 + 0.125 \cdot 0.044828$
  * $\text{EstimatedRTT}_1 = 0.875 \cdot 0.022414 + 0.125 \cdot 0.044828$
  * $\text{EstimatedRTT}_1 = 0.01961225 + 0.0056035 = \mathbf{0.025216\text{ с}}$

**11. Какова пропускная способность (throughput) TCP-соединения? Объясните метод расчета.**

* **Метод расчета:**
  1.  **Общий объем переданных данных:** Определяется по полю Acknowledgement Number в последнем сегменте, отправленном сервером, который подтверждает весь файл (например, Frame 32). В данном трассировке это примерно 146200 байт.
  2.  **Общее время передачи:** Определяется как разница между временем получения последнего ACK и временем отправки первого SYN-сегмента.
    * Время отправки SYN (Frame 1): 0.000000$\text{ с}$.
    * Время получения последнего ACK (Frame 32): $\approx 1.583561\text{ с}$.
    * Общее время = 1.583561$\text{ с}$

* **Расчет:**
  $$\text{Пропускная способность} = \frac{146200\text{ байт}}{1.583561\text{ с}} \approx 92322.96\text{ байт/с}$$
