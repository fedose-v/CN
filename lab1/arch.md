## Основные Компоненты и Их Роли 
* MessageData: Структура, содержащая поля для имени и числа как клиента, так и сервера. Используется для унификации передачи данных между логикой и менеджером сокетов.
* Config: Статический контейнер для общих настроек (порт, IP, размер буфера, фиксированные имена/числа).

## SocketProvider (Низкоуровневый Уровень)
* Выступает в роли Фасада для POSIX-функций (socket, send, recv, close).
* Отвечает за низкоуровневую коммуникацию, гарантируя, что формат сообщения (строка ИМЯ:ЧИСЛО) соответствует требованиям приложения.

## Server (Серверный Уровень)
* Метод Initialize(): Создает слушающий сокет, выполняет bind и listen на заданном порту.
* Метод Start(): Содержит основной цикл сервера (while(true)) и вызывает accept() для приема новых подключений.
* Метод ProcessClient():
  * Принимает сообщение от клиента
  * Разбирает его
  * Выполняет логику
  * Отправляет ответное сообщение с числом сервера
  * Закрывает сокет клиента

* Механизм завершения: Если клиент присылает число вне диапазона [1,100], ProcessClient() возвращает false, что приводит к выходу из цикла Start() и завершению работы сервера.

## Client (Клиентский Уровень)
* Метод GetClientNumber(): Обеспечивает безопасный ввод целого числа от пользователя.
* Метод EstablishConnection(): Создает сокет и выполняет connect() к заданному IP/порту.
* Метод Start():
  * Получает число от пользователя
  * Подключается к серверу
  * Отправляет сообщение
  * Принимает ответ (только если число в диапазоне)
  * Выводит финальный результат взаимодействия
*   Закрывает сокет

## Взаимодействие Компонентов (Поток Данных)
* Запуск: server_main.cpp запускает Server::Start(). Server инициализируется и входит в цикл accept.
* Действие Клиента: client_main.cpp запускает Client::Start(). Клиент запрашивает число у пользователя.
* Подключение: Client::EstablishConnection() использует SocketProvider::CreateSocket() и connect().
* Запрос: Client::Start() использует SocketProvider::CreateMessage() для форматирования и SocketProvider::SendData() для отправки.
* Прием на Сервере: Server::Start() вызывает accept(), после чего управление передается Server::ProcessClient().
* Обработка: ProcessClient() использует SocketProvider::ReceiveData() и SocketProvider::ParseMessage() для получения данных клиента.
* Ответ: ProcessClient() формирует ответное сообщение и отправляет его через SocketProvider::SendData().
* Получение Ответа Клиентом: Client::Start() вызывает SocketProvider::ReceiveData(), разбирает его и выводит результат с помощью Client::DisplayResult().
* Завершение: Оба, Server::ProcessClient() и Client::Start(), используют SocketProvider::CloseSocket() для корректного закрытия соединений.

## Используемые Технологии
* Язык: C++11 (для использования std::string, std::to_string, и std::stoi).
* Платформа: Ubuntu/Linux.
* Сетевой API: POSIX Sockets (заголовки sys/socket.h, arpa/inet.h, unistd.h, netinet/in.h).
* Протокол: TCP (SOCK_STREAM).
